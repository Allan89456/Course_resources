# Course resources
***
Manage course resources.
## Installation
***
This project use XAMPP.
When Apache and MySQL are ready, go to http://localhost/phpmyadmin.
Create the account 'rootTest' with the password 'root123'. Give it 'Data' rights.
Create the database 'roottest'.
Execute the given SQL script.

There are three sorts of users: visitors, connected users, and admins.
The two admins created are A0001 and A0002. Their passwords are 'mdp'.
The site is available at http://localhost/SITE/index.php
